# SLC Gene Family Brain Transcript Atlas

A scientific web atlas for exploring the SLC (Solute Carrier) gene family with a focus on brain expression and transcriptomics.

## Views

1. **Genes** — Searchable/sortable annotation table with expandable transcript rows
2. **Clustering** — Similarity by amino acid sequence, DNA sequence, and RNA co-expression
3. **Conservation** — Gene × species heatmap with dendrograms
4. **Genome Browser** — Genomic landscape with omics BigWig tracks, GWAS
5. **Expression** — RNA and protein abundance heatmaps (gene × tissue, gene × cell type)
6. **Structure** — AlphaFold protein structures and predicted drug binding sites
7. **PET-SCAN** — PET imaging data
