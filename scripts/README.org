#+title: Data Pipeline

* Data Pipeline
The pipeline has two independent phases with a clean handoff between them:

1. *Preprocessing* (=scripts/preprocess/=)---the gene-family-specific part. It takes raw downloads and fetches biological data, writing the result to a standard-format dataset in =backend/data/dataset/=.
2. *Build* (=scripts/build/=)---the general, family-agnostic part. It reads only =backend/data/dataset/= and writes the five Parquet files the API serves, without needing to know anything about HGNC, Ensembl, GTEx, or any particular gene family.

*Every preprocessing fetch script is optional*, as long as each file matches the format below:

** The standard-format dataset (=backend/data/dataset/=)

|---------------------+-----------------------------------------------------------------------------------------------------------------------------------+--------------------|
| File                | Columns / format                                                                                                                  | Used by            |
|---------------------+-----------------------------------------------------------------------------------------------------------------------------------+--------------------|
| =genes.tsv=         | id, symbol, name, chromosome, start, end, strand, length, alias, category, family, family_name, function_brief                     | gene tables        |
| =transcripts.tsv=   | id, gene_id, name, type, start, end, length                                                                                       | gene tables        |
| =cds.fasta=         | FASTA keyed by gene id                                                                                                             | clustering         |
| =protein.fasta=     | FASTA keyed by gene id                                                                                                             | clustering         |
| =expression.parquet=| gene_id + one column per sample (Float32 TPM)                                                                                      | clustering         |
| =sample_tissue.tsv= | sample_id, tissue, tissue_detail                                                                                                   | clustering         |
| =orthologs.tsv=     | gene_id, species, target_gene_id, target_protein_id, perc_id, perc_id_r1, perc_pos, dn_ds, orthology_type, ortholog_count          | conservation       |
| =species.tsv=       | species, species_label, taxon_id                                                                                                   | conservation       |
| =species_tree.nwk=  | Newick, leaves = species                                                                                                           | conservation       |
|-------------------+------------------------------------------------------------------------------------------------------------------------------------+--------------------|

** Prerequisites (raw downloads you provide)
Place these in =backend/data/raw/= before running preprocess:

| File                             | Source                                                                            |
|----------------------------------+-----------------------------------------------------------------------------------|
| =hgnx_family.txt=                | Download from [[https://www.genenames.org/data/genegroup/#!/group/2192][HGNC gene group]] → "Download this gene family" (TSV)                 |
| =GTEx_Analysis_*_gene_tpm.parquet= | [[https://gtexportal.org/home/downloads/adult-gtex/bulk_tissue_expression][GTEx portal]] --- bulk tissue gene TPMs, converted to Parquet (only for clustering) |

** Quick start
#+begin_src sh
# Full pipeline: preprocess (raw -> dataset) then build (dataset -> parquet)
python scripts/run_pipeline.py

# Run a single phase
python scripts/preprocess/run.py        # gene-family-specific, network-facing
python scripts/build/run.py             # general, dataset -> served parquet

# Skip the heavy/optional views (applies to both phases)
python scripts/run_pipeline.py --skip-clustering      # skip steps that need GTEx + sequences
python scripts/run_pipeline.py --skip-conservation    # skip orthologs + species tree

# Use a non-default HGNC file
python scripts/run_pipeline.py path/to/my_family.txt
#+end_src

On a fresh run the preprocess phase stops after writing =reference/family_names.md= so you can choose display names (the first bullet under each heading).

** Preprocess steps (=scripts/preprocess/=, family-specific)
- =fetch_family_names.py= :: Uses HGNC API to get each family's aliases. Edit =reference/family_names.md= to continue.
- =annotate_genes.py= :: Joins the HGNC TSV with the chosen family names and derives the short family key (=gene_family_utils.derive_family_keys=) to output =raw/annotation.tsv=.
- =fetch_ensembl_genes.py= :: Puts gene/transcript coordinates from Ensembl BioMart into =raw/ensembl_genes.tsv=.
- =fetch_ncbi_summaries.py= :: Puts gene-summary blurbs from NCBI E-utilities in =raw/ncbi_gene_summaries.tsv=.
- =assemble_genes.py= :: Joins annotation + Ensembl + NCBI into =dataset/genes.tsv= + =dataset/transcripts.tsv=, along with any other custom modifications such as removing pseudo genes.
- =subset_expression.py= :: Subsets the raw GTEx TPM matrix to the dataset genes to make =dataset/expression.parquet= and normalized =dataset/sample_tissue.tsv=.
- =fetch_sequences.py= :: Uses canonical CDS + protein sequences from Ensembl REST for =dataset/cds.fasta= and =dataset/protein.fasta=.
- =fetch_orthologs.py= :: Fetches Ensembl Compara orthologs for the species in =reference/species.tsv= and =dataset/orthologs.tsv=.
- =fetch_species_tree.py= :: Fetch species dendrogram via a swappable source (=species_tree_sources.py=; default Ensembl Compara). Stores output in =dataset/species_tree.nwk= and =dataset/species.tsv=.

** Build steps (=scripts/build/=, general)
- =build_gene_tables.py= :: Converts =dataset/genes.tsv= and =transcripts.tsv= to =genes.parquet= and =transcripts.parquet=.
- =build_clustering.py= :: Runs MAFFT + UPGMA across four methods (amino-acid, DNA, all-tissue co-expression, brain co-expression) and outputs to =clustering.parquet=.
- =build_conservation.py= :: Converts a gene × species matrix and species-tree node table to =conservation.parquet= and =species_tree.parquet=.

** Curated inputs (=reference/=)
- =family_names.md= :: Per-family display names written by =fetch_family_names.py=. Reorder items (the first entry is used).
- =species.tsv= :: Conservation species set and cross-source name mappings (=ensembl_name=, =display_name=, =taxon_id=, =timetree_name=, =ucsc_name=). Edit and re-run the conservation steps to change which species appear.
- =species_tree_timetree.nwk= / =species_tree_ucsc.nwk= :: curated Newicks for the non-Ensembl tree sources (only when that source is used).

** Data layout
#+begin_example
backend/data/
  genes.parquet          ← served by /api/genes
  transcripts.parquet    ← served by /api/genes/{id}/transcripts
  clustering.parquet     ← served by /api/clustering
  conservation.parquet   ← served by /api/conservation
  species_tree.parquet   ← served by /api/conservation/species-tree

  dataset/               ← standard-format handoff (preprocess output, not served)
    genes.tsv
    transcripts.tsv
    cds.fasta
    protein.fasta
    expression.parquet
    sample_tissue.tsv
    orthologs.tsv
    species.tsv
    species_tree.nwk

  raw/                   ← raw downloads + fetch intermediates (not served)
    hgnc_family.txt          manual download from HGNC
    GTEx_*_gene_tpm.parquet  manual download from GTEx portal
    annotation.tsv           output of annotate_genes
    ensembl_genes.tsv        output of fetch_ensembl_genes
    ncbi_gene_summaries.tsv  output of fetch_ncbi_summaries
    aligned_*.fasta          intermediates of build_clustering
    tree_*.nwk               per-method Newicks from build_clustering

reference/                 ← hand-curated inputs
#+end_example

** Utilities
Non-pipeline helper scripts are in =scripts/utils/=:

- =tsv_to_parquet.py= / =parquet_to_tsv.py= :: general-purpose converters
- =reuse_header.sh= / =reuse_header_all.sh= :: add REUSE/SPDX license headers
