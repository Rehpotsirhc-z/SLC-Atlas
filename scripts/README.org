#+title: Data Pipeline

* Data Pipeline
The pipeline has two independent phases with a clean handoff between them:

1. *Preprocessing* (=scripts/preprocess/=)---the gene-family-specific part. It takes raw downloads and fetches biological data, writing the result to a standard-format dataset in =backend/data/dataset/=.
2. *Build* (=scripts/build/=)---the general, family-agnostic part. It reads only =backend/data/dataset/= and writes the five Parquet files the API serves, without needing to know anything about HGNC, Ensembl, GTEx, or any particular gene family.

*Every preprocessing fetch script is optional*, as long as each file matches the format below:

** The standard-format dataset (=backend/data/dataset/=)

|----------------------+--------------------------------------------------------------------------------------------------------------------+------------------------|
| File                 | Columns / format                                                                                                   | Used by                |
|----------------------+--------------------------------------------------------------------------------------------------------------------+------------------------|
| =genes.tsv=            | id, symbol, name, chromosome, start, end, strand, length, alias, category, family, family_name, function_brief     | gene tables            |
| =transcripts.tsv=      | id, gene_id, name, type, start, end, length                                                                        | gene tables            |
| =cds.fasta=            | FASTA keyed by gene id                                                                                             | clustering             |
| =protein.fasta=        | FASTA keyed by gene id                                                                                             | clustering             |
| =expression.parquet= | gene_id + one column per sample (Float32 TPM)                                                                      | clustering, expression |
| =sample_tissue.tsv=    | sample_id, tissue, tissue_detail                                                                                   | clustering, expression |
| =orthologs.tsv=        | gene_id, species, target_gene_id, perc_id, perc_id_r1, perc_pos, orthology_type, ortholog_count                    | conservation           |
| =species.tsv=          | species, species_label, taxon_id                                                                                   | conservation           |
| =species_tree.nwk=     | Newick, leaves = species                                                                                           | conservation           |
| =structure/=           | generated by the structure steps, not hand-authored (see below)                                                    | structure              |
|----------------------+--------------------------------------------------------------------------------------------------------------------+------------------------|

*** The structure sub-dataset (=backend/data/dataset/structure/=)
The structure steps take =genes.tsv= as their only input and generate the rest, keeping it in its own subfolder. Delete the folder to force a refetch; delete a single file under =models/= to refetch just that model.

| File               | Columns / format                                                                                     |
|--------------------+------------------------------------------------------------------------------------------------------|
| =uniprot_map.tsv=    | gene_id, symbol, uniprot_accession, uniprot_id, uniprot_length, seq_agreement, id_route              |
| =features.tsv=       | gene_id, uniprot_accession, feature_type, start, end, description, ligand_name, ligand_chebi, ligand_label |
| =structures.tsv=     | gene_id, uniprot_accession, afdb_entry_id, afdb_version, model_url, ..., alphafill_page_url          |
| =experimental.tsv=   | gene_id, uniprot_accession, pdb_id, method, resolution, coverage, chains, ligand_ccd, ...            |
| =confidence.parquet= | gene_id, uniprot_accession, plddt (one 0-100 score per residue)                                      |
| =models/=            | one binary-CIF coordinate file per accession (~97 MB for 462 genes)                                  |

=feature_type= is one of =transmembrane=, =intramembrane=, =topological_domain=, =binding_site=, =active_site=, =glycosylation=, =disulfide_bond=, =signal_peptide=. The last three are never drawn: each pins its residue to the non-cytoplasmic face, which is how the figure orients a protein UniProt gives no topological domains for. =build_structure.py= reports any other value and the figure ignores it.

** Prerequisites (raw downloads you provide)
Place these in =backend/data/raw/= before running preprocess:

| File                             | Source                                                                            |
|----------------------------------+-----------------------------------------------------------------------------------|
| =hgnx_family.txt=                | Download from [[https://www.genenames.org/data/genegroup/#!/group/2192][HGNC gene group]] → "Download this gene family" (TSV)                 |
| =GTEx_Analysis_*_gene_tpm.parquet= | [[https://gtexportal.org/home/downloads/adult-gtex/bulk_tissue_expression][GTEx portal]] --- bulk tissue gene TPMs, converted to Parquet (only for clustering) |

** Quick start
#+begin_src sh
# Full pipeline: preprocess (raw -> dataset) then build (dataset -> parquet)
python scripts/run_pipeline.py

# Run a single phase
python scripts/preprocess/run.py        # gene-family-specific, network-facing
python scripts/build/run.py             # general, dataset -> served parquet

# Skip the heavy/optional views (applies to both phases)
python scripts/run_pipeline.py --skip-clustering      # skip steps that need GTEx + sequences
python scripts/run_pipeline.py --skip-conservation    # skip orthologs + species tree
python scripts/run_pipeline.py --skip-expression      # skip the gene x tissue expression matrix
python scripts/run_pipeline.py --skip-structure       # skip protein models, topology, coordinate downloads

# How many experimental structures to mirror (predicted models are always mirrored)
python scripts/run_pipeline.py --skip-pdb-models      # mirror none; the viewer streams them all
python scripts/run_pipeline.py --pdb-models all       # mirror every entry (~1.3 GB), for offline use

# Use a non-default HGNC file
python scripts/run_pipeline.py path/to/my_family.txt
#+end_src

On a fresh run the preprocess phase stops after writing =reference/family_names.md= so you can choose display names (the first bullet under each heading).

** Preprocess steps (=scripts/preprocess/=, family-specific)
- =fetch_family_names.py= :: Uses HGNC API to get each family's aliases. Edit =reference/family_names.md= to continue.
- =annotate_genes.py= :: Joins the HGNC TSV with the chosen family names and derives the short family key (=gene_family_utils.derive_family_keys=) to output =raw/annotation.tsv=.
- =fetch_ensembl_genes.py= :: Puts gene/transcript coordinates from Ensembl BioMart into =raw/ensembl_genes.tsv=.
- =fetch_ncbi_summaries.py= :: Puts gene-summary blurbs from NCBI E-utilities in =raw/ncbi_gene_summaries.tsv=.
- =assemble_genes.py= :: Joins annotation + Ensembl + NCBI into =dataset/genes.tsv= + =dataset/transcripts.tsv=, dropping the symbols listed in =reference/pseudogene_exclusions.txt=.
- =subset_expression.py= :: Subsets the raw GTEx TPM matrix to the dataset genes to make =dataset/expression.parquet= and normalized =dataset/sample_tissue.tsv=.
- =fetch_sequences.py= :: Uses canonical CDS + protein sequences from Ensembl REST for =dataset/cds.fasta= and =dataset/protein.fasta=.
- =fetch_orthologs.py= :: Fetches Ensembl Compara orthologs for the species in =reference/species.tsv= and =dataset/orthologs.tsv=.
- =fetch_species_tree.py= :: Fetch species dendrogram via a swappable source (=species_tree_sources.py=; default Ensembl Compara). Stores output in =dataset/species_tree.nwk= and =dataset/species.tsv=.
- =fetch_uniprot_map.py= :: Maps =dataset/genes.tsv= gene IDs to UniProt accessions (HGNC route via =raw/annotation.tsv= when present, otherwise Ensembl), cross-checks against =protein.fasta=, and writes =dataset/structure/uniprot_map.tsv=. Hand fixes go in =reference/uniprot_overrides.tsv=.
- =fetch_protein_features.py= :: Transmembrane, intramembrane, topological-domain, binding-site and active-site features from UniProt into =dataset/structure/features.tsv=, in UniProt canonical numbering, plus the glycosylation, disulfide and signal-peptide features that orient a protein with no topological domains.
- =fetch_structures.py= :: 3D-Beacons plus the AlphaFold DB API into =dataset/structure/structures.tsv= and =experimental.tsv=. Model URLs are stored as the APIs report them, never rebuilt, because AlphaFold retires old version suffixes.
- =download_models.py= :: Downloads each predicted model into =dataset/structure/models/=, skipping anything already on disk.
- =download_experimental_models.py= :: Mirrors experimental coordinates from RCSB into =dataset/structure/models/pdb/=. =--pdb-models best= (default) takes the best-resolved entry per gene, =all= takes every entry, =none= mirrors nothing. The viewer streams whatever is missing straight from =models.rcsb.org=, so this only decides how much works offline.
- =fetch_confidence.py= :: Per-residue AlphaFold confidence (pLDDT) into =dataset/structure/confidence.parquet=, which the topology figure plots along the residue axis.

** Build steps (=scripts/build/=, general)
- =build_gene_tables.py= :: Converts =dataset/genes.tsv= and =transcripts.tsv= to =genes.parquet= and =transcripts.parquet=.
- =build_clustering.py= :: Orchestrates six methods (amino-acid, DNA, all-tissue co-expression, brain co-expression, ortholog identity, and flat family grouping) into =clustering.parquet=.
  - =clustering_metrics.py= :: MAFFT alignment and the pairwise distance metrics.
  - =tree_table.py= :: UPGMA/family-grouping to flat node rows plus Newick; owns =CLUSTERING_SCHEMA=.
- =build_conservation.py= :: Converts a gene × species matrix and species-tree node table to =conservation.parquet= and =species_tree.parquet=.
- =build_expression.py= :: Melts the sample-level GTEx TPM matrix and aggregates mean TPM per gene × tissue (both the 31 coarse GTEx tissues and, within Brain, the ~13 fine-grained subregions) into =expression.parquet=.
- =build_structure.py= :: Joins =dataset/structure/= into =structure/{structure,features,experimental,sources}.parquet= and copies the coordinate files to =structure/models/=. Collapses the per-segment rows 3D-Beacons returns to one row per PDB entry, and drops a pLDDT array whose length disagrees with =uniprot_length=, since the two cannot then be aligned. Writes nothing when =dataset/structure/= is absent, and the API then reports the structure capability as unavailable.

** Curated inputs (=reference/=)
- =family_names.md= :: Per-family display names written by =fetch_family_names.py=. Reorder items (the first entry is used).
- =species.tsv= :: Conservation species set and cross-source name mappings (=ensembl_name=, =display_name=, =taxon_id=, =timetree_name=, =ucsc_name=). Edit and re-run the conservation steps to change which species appear.
- =pseudogene_exclusions.txt= :: Approved symbols =assemble_genes.py= drops, one per line (blank lines and =#= comments ignored).
- =species_tree_timetree.nwk= / =species_tree_ucsc.nwk= :: curated Newicks for the non-Ensembl tree sources (only when that source is used).

** Data layout
#+begin_example
backend/data/
  genes.parquet          ← served by /api/genes
  transcripts.parquet    ← served by /api/genes/{id}/transcripts
  clustering.parquet     ← served by /api/clustering
  conservation.parquet   ← served by /api/conservation
  species_tree.parquet   ← served by /api/conservation/species-tree
  expression.parquet     ← served by /api/expression

  structure/             ← served by /api/structure (optional; --skip-structure omits it)
    structure.parquet        one row per gene: accession, model, pLDDT, feature counts
    features.parquet         topology and binding features
    experimental.parquet     PDB entries per gene (metadata only)
    sources.parquet          per-source version, retrieval date, licence
    models/                  binary-CIF coordinates, one per accession
      pdb/                   mirrored experimental entries, if any were downloaded

  dataset/               ← standard-format handoff (preprocess output, not served)
    genes.tsv
    transcripts.tsv
    cds.fasta
    protein.fasta
    expression.parquet
    sample_tissue.tsv
    orthologs.tsv
    species.tsv
    species_tree.nwk

  raw/                   ← raw downloads + fetch intermediates (not served)
    hgnc_family.txt          manual download from HGNC
    GTEx_*_gene_tpm.parquet  manual download from GTEx portal
    annotation.tsv           output of annotate_genes
    ensembl_genes.tsv        output of fetch_ensembl_genes
    ncbi_gene_summaries.tsv  output of fetch_ncbi_summaries
    aligned_*.fasta          intermediates of build_clustering
    tree_*.nwk               per-method Newicks from build_clustering

reference/                 ← hand-curated inputs
#+end_example

** Shared code (=scripts/lib/=)
Imported by both phases, so neither phase has to import the other:

- =http.py= :: retrying HTTP helpers (=get_json=, =post_json=, =post_form=, =fetch_text=); every request retries on 429 honouring =Retry-After=
- =dataset_schema.py= :: =GENE_SCHEMA= / =TRANSCRIPT_SCHEMA=, the dataset gene-table column contract
- =reporting.py= :: =report_missing(label, items)= stderr diagnostics, capped at 20 listed items
- =orchestration.py= :: =run_script= / =run_parallel=; a failing step always raises =SystemExit=
- =pipeline_args.py= :: the =--skip-*= / =hgnc_file= argparse shared by =run_pipeline.py= and both phase runners

Scripts reach it by putting =scripts/= on =sys.path= and importing =lib.<module>=.

** Utilities
Non-pipeline helper scripts are in =scripts/utils/=:

- =convert.py= :: TSV <-> Parquet, dispatching on the input extension (=tsv_to_parquet.py= / =parquet_to_tsv.py= remain as aliases)
- =reuse_header.sh= / =reuse_header_all.sh= :: add REUSE/SPDX license headers
